# Smart Event Management System

A Smart College Event Management System built using Python and SQLite with features like event scheduling, student registration, conflict detection, and automated ticket generation.

## Features
- Add / View / Delete Events
- Student Registration System
- Ticket ID Generation
- Event Registration Limit (max 3)
- Clean database design (SQLite)

## Unique Features
- Smart registration limit system
- Auto ticket generation
- Modular Python structure
- Real-world simulation logic

## Tech Stack
- Python
- SQLite
